# Login-Authentication-UI
A clean and responsive Login Authentication Interface built as a front-end development project. The project focuses on creating a simple, modern, and user-friendly authentication experience with a dark background, rounded login card, and orange primary action button.

Features
Clean and minimal login interface
Email input field
Password input field
Sign-in button
Registration link for new users
Responsive layout
Modern rounded-card design
Dark background with contrasting authentication panel
Simple and intuitive user experience
🛠️ Technologies Used
HTML5 — Page structure
CSS3 — Styling, layout, responsiveness, and visual design

 Design
The interface was designed with simplicity and usability in mind.

Color direction
Dark navy background
White authentication card
Orange primary action
Neutral gray form elements

The goal was to create an authentication interface that is simple, readable, and easy to use without unnecessary visual elements.
